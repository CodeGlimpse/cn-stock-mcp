# 对外一次性销售准备清单

这是一份交付前的内部闸门，不是法律意见。只有所有“必须完成”项目有记录，才可以把本项目作为一次性数字商品交付给客户。

## 必须完成

- [ ] 订单写明固定版本、wheel SHA256、交付物和下载地址。
- [ ] 订单写明支持的操作系统、Python 版本、MCP Host 名称/版本和支持期限。
- [ ] 订单写明首次验收期限、安装失败补救次数、退款条件、联系方式和工单渠道。
- [ ] 客户确认自行申请、支付、保管和轮换智兔 Token；卖方不接收 Token。
- [ ] 客户确认智兔额度、AI Host/模型费用、Windows/Python/网络费用不包含在软件售价中。
- [ ] 客户确认 AKShare、智兔和下游数据的展示、缓存、商业使用与再分发须遵守各自条款。
- [ ] 销售页和交付文档明确“不提供任何投资参考、投资建议、风险建议、买卖指令或收益承诺”。
- [ ] 使用客户本人账号完成 Windows 标准用户安装、`--doctor`、MCP 握手和一次指定查询验收。

## 不得承诺

- 任意云端聊天 AI 都能操作客户电脑并自动部署；
- 所有 Host 的历史和未来版本永久兼容；
- AKShare、智兔或下游接口的 SLA、实时性、字段稳定性；
- 数据结果、候选分数或风险标签能够带来收益；
- 当前公开 MIT 核心代码具有独占性或不可再分发性。
