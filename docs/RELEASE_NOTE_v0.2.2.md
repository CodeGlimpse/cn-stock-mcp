# cn-stock-mcp v0.2.2

本版本在 v0.2.1 的公开发布基础上，继续收紧客户部署、数据质量和诊断边界。

## 主要变化

- 增加 Token 来源冲突诊断：用户配置文件优先，旧版环境变量只作为兼容回退，诊断不显示凭据。
- Zhitu 单 Token 网络超时时会尝试已配置的备用 Token。
- freshness 会拒绝明显位于未来的上游时间字段，并返回可机读警告。
- data_quality 增加价格/成交量/金额及 high-low 顺序异常检测。
- stock_snapshot 返回 best-effort 取消语义，明确已运行的同步上游请求可能继续到 Provider 自身超时。
- 增加 Windows CPython 3.13 运行时依赖约束文件，并在发布附件、SHA256 和审计流程中验证。
- 增加一次性销售准备清单，明确 Token、数据授权、Host 支持和退款/支持条款必须在销售前确定。

## 重要边界

- 客户本人申请、支付、保管和输入智兔 Token；卖方和 AI Agent 不接收或读取 Token。
- 本项目不提供投资参考、投资建议、风险建议、买卖指令或收益承诺。
- AKShare、智兔及下游接口可能延迟、缺失、限流或改变字段；数据授权由实际使用者按上游条款负责。
- Windows 首发验收固定为普通 CPython 3.13；当前没有 GUI 安装器、持久化观察列表或内置定时任务。
