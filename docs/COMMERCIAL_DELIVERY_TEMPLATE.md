# 一次性销售与交付条款模板

> 这是产品交付清单模板，不是法律意见。卖方应按销售地区、平台规则和实际服务内容请专业人士审阅，并在成交前填写方括号内容。

## 1. 交付物

- 固定版本：`cn-stock-mcp==0.2.1`
- PyPI 包、同版本 GitHub Release、SHA256 校验文件和 SBOM
- 客户部署文档与 AI 自部署提示词
- 已约定 MCP Host 的配置指导与首次验收
- 技术支持期：自交付验收日起 `[7/14/30]` 天

验收以版本、hash、`--doctor`、10 工具 retail 档、MCP initialize/tools/list 和一次指定查询为准。第三方市场在验收时无数据，不自动等同于软件安装失败，应按错误类型区分安装、网络、Token、额度和上游故障。

## 2. 客户自行准备并承担

- Windows、受支持的普通 CPython、本地执行型 AI Agent/MCP Host 和网络
- 客户本人向智兔申请或购买的 Token、额度及相关费用
- AI Host、模型或其他第三方服务费用
- 上游服务条款、商业展示、缓存和再分发权限
- 投资判断和对数据的独立核验

卖方不接收、不保管、不代填 Token；客户本人完成登录、验证码、付款/套餐选择和 Token 输入。

## 3. 不包含的承诺

- 不保证任意云端聊天 AI 能操作客户电脑或自动部署
- 不保证所有 Host 历史/未来版本永久兼容
- 不保证 AKShare、智兔及下游接口的 SLA、实时性、完整性或字段不变
- 不包含终身免费维护、Windows GUI 安装器、持久化观察列表或内置定时任务，除非订单另行书面约定
- 不连接券商、不保存交易账户、不执行买卖或自动交易
- 不提供投资参考、投资建议、风险建议、买卖指令、收益承诺或个性化适当性判断

当前公开核心代码按仓库中的 MIT License 提供。收费对象可以是固定版本整理、部署提示词、安装配置、验收、支持和另行开发的私有扩展；不得把公开 MIT 核心宣传为独占软件或承诺客户不能按 MIT 条款再使用、修改或分发。私有定制代码的权利归属应在订单中单独写明。

## 5. 支持与变更

支持期内处理可复现的安装、配置、MCP 连接和本版本缺陷。因客户环境、Host 升级、Token/额度、代理、防火墙或第三方接口变化产生的适配，超出首单范围时应先报价。新版本升级不自动包含在一次性售价中，除非订单另行约定。
