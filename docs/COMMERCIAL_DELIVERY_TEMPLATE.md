# 免费开源软件的部署与运行售后服务

GitHub 代码免费开源，核心采用 MIT。**收费仅针对部署和代码运行售后，不收取代码使用费，不出售第三方数据或 Token。** 报价、成交渠道和联系入口由订单处理。技术准备状态见 [SALE_READINESS.md](SALE_READINESS.md)，服务约定须符合平台规则及适用的强制法律义务。

## 1. 交付物与约定环境

- 适用固定版本：`cn-stock-mcp==0.2.3`，交付前核验公开 Release 与校验文件。
- 同版本 wheel、sdist、依赖约束、SHA256 清单、SBOM 和可查询的构建来源证明。
- 客户部署文档、13 款 Windows Agent 配置指南、验收脚本、第三方许可证原文和 AI 部署提示词。
- 首发环境：Windows 11 x64、普通 CPython 3.13、Codex、本地 stdio、`retail_v1_preview` 10 工具。
- 实际 Codex 客户端类型/版本、软件版本与 wheel SHA256 写入交付记录。其他 Host 仅保留配置参考。

研发阶段进行离线测试、打包及文档检查；经营者决定本轮不进行真实行情和实际 AI Host 验收，不宣传全部客户端实测通过或所有上游已验证稳定。

客户验收在服务交付后进行，首次验收期为交付起 **3 天**。按订单约定检查版本/hash、本地自检、MCP 连接、10 工具目录及客户认可的查询或问答。客户选择不进行真实查询时，由双方记录实际验收范围及未执行项；未执行不写成通过，超期未回复不自动视为成功。研发阶段跳过实测与交付后的客户验收分别记录。

## 2. 售后支持与补救

- 验收后提供 **7 天部署及代码运行售后支持**。
- 支持请求在 **2 个工作日内响应**；响应时限不是保证解决时限。
- 首次安装失败最多补救 **2 次**，累计补救时间不超过 **7 天**。
- 在约定环境中仍无法完成验收时，**按成交平台规则退款**。
- 上游暂时无数据、Token/额度异常或网络限制，按错误类别记录并协商处理，不擅自写为验收通过，也不以此排除平台赋予的退款权利。

支持处理可复现的本版本安装、配置、MCP 连接和代码运行问题，以及缺陷的诊断与修复安排。客户环境或 Host 升级、代理、防火墙、第三方接口变化引起的额外适配，另行约定范围。新版本升级和新增功能不自动包含在本次服务内。

## 3. 客户自行准备

- 约定的操作系统、Python、Codex、模型服务及网络。
- 客户本人向智兔申请或购买、保管和轮换的 Token 与额度。
- 第三方服务费用，以及实际用途涉及的数据展示、缓存、商业使用和再分发许可。
- 对行情数据及 AI 输出的独立核验。

卖方不接收、不保管、不代填 Token。登录、验证码、第三方服务购买及 Token 输入由客户本人完成。Token、配置文件和原始日志不归档到订单或工单。
