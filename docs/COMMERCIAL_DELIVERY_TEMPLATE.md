# 一次性交付与售后条款

本模板采用已确认的首发范围。订单关联信息由具体交付填写；项目不决定报价。技术准备状态见 [SALE_READINESS.md](SALE_READINESS.md)。条款须符合实际成交平台规则及适用的强制法律义务。

## 1. 交付物与约定环境

- 目标固定版本：`cn-stock-mcp==0.2.3`，当前为发布准备，公开 Release 核验完成后才能交付。
- 同版本 wheel、sdist、依赖约束、SHA256 清单、SBOM 和可查询的构建来源证明。
- 客户部署文档、Codex 配置模板、验收脚本、AI 部署提示词。
- 首发环境：Windows 11 x64、普通 CPython 3.13、Codex、本地 stdio、`retail_v1_preview` 10 工具。
- 实际 Codex 客户端类型/版本、软件版本与 wheel SHA256 写入交付记录。其他 Host 仅保留配置参考。

交付时点由订单或双方交付确认记录确定。首次验收期为交付起 **3 天**。验收依据包括安装版本和 hash、本地自检、MCP 连接、10 工具目录、已约定样本查询以及真实 Codex 问答；未执行或部分失败必须如实记录，不因超期未回复自动视为验收成功。

## 2. 售后支持与补救

- 验收后提供 **7 天安装配置支持**。
- 支持请求在 **2 个工作日内响应**；响应时限不是保证解决时限。
- 首次安装失败最多补救 **2 次**，累计补救时间不超过 **7 天**。
- 在约定环境中仍无法完成验收时，**按成交平台规则退款**。
- 上游暂时无数据、Token/额度异常或网络限制，按错误类别记录并协商处理，不擅自写为验收通过，也不以此排除平台赋予的退款权利。

支持处理可复现的本版本安装、配置、MCP 连接问题，以及缺陷的诊断与修复安排。客户环境或 Host 升级、代理、防火墙、第三方接口变化引起的额外适配，另行约定范围。新版本升级和新增功能不自动包含在本次交付内。

## 3. 客户自行准备

- 约定的操作系统、Python、Codex、模型服务及网络。
- 客户本人向智兔申请或购买、保管和轮换的 Token 与额度。
- 第三方服务费用，以及实际用途涉及的数据展示、缓存、商业使用和再分发许可。
- 对行情数据及 AI 输出的独立核验。

卖方不接收、不保管、不代填 Token。登录、验证码、第三方服务购买及 Token 输入由客户本人完成。Token、配置文件和原始日志不归档到订单或工单。

公开核心代码采用仓库 MIT License；收费交付可包含版本整理、部署、配置、验收、支持和另行约定的开发服务。不得把 MIT 核心描述为独占软件，不限制客户依据该许可证使用、修改和分发。私有定制代码的权利另行书面约定。

本项目不提供第三方数据授权，不承诺上游 SLA、数据实时性、完整性或字段稳定性。数据权限记录见 [DATA_RIGHTS_REGISTER.md](DATA_RIGHTS_REGISTER.md)。

本次交付不包含永久兼容所有 Host、终身维护、Windows GUI 安装器、持久化观察列表或内置定时任务。工具不连接券商、不保存交易账户、不执行交易，不提供投资参考、投资建议、风险建议、买卖指令、收益承诺或个性化投资服务。
