# Privacy Notice

- 默认无遥测、无远程管理服务、无账户资料库。
- 服务只在用户调用工具时访问 AKShare、Zhitu 及其下游公开数据接口。
- token 和本地配置由用户控制，默认位于 `%LOCALAPPDATA%\cn-stock-mcp\config.json`；项目不上传配置文件。
- 日志和诊断输出应只包含工具名、状态、时间、来源和错误类别，不包含 token、配置内容或完整带凭据 URL。
- 用户自行配置代理时，代理运营方可能观察到请求目标和协议内容；请按组织隐私政策配置网络。
- 市场数据可能包含来自第三方的公开信息；用户必须自行核验来源授权、缓存和再分发范围。
