# cn-stock-mcp 产品介绍

## 一句话说明

`cn-stock-mcp` 是一个面向 AI Agent 的中国证券市场数据与分析 MCP 工具。它让 Codex、Claude Code、OpenClaw、Hermes Agent 等 AI Host 能够通过自然语言调用行情、历史、财务、板块、资金流、事件和复盘能力。

它的定位是：

> 帮助 AI 更快整理市场信息、发现值得进一步研究的线索，并把“观察—分析—复盘”变成可重复的工作流。

它不是荐股软件、交易终端或券商下单系统。

## 适合什么人

- 希望让 AI 帮忙做盘前/盘后信息整理的投资者
- 需要维护观察列表、定期复盘的个人或研究团队
- 想把行情、板块和财务数据接入自有 AI Agent 的开发者
- 需要通过统一 MCP 接口使用多类市场数据的团队

## 面向 AI 的核心卖点

### 1. 用自然语言完成市场研究流程

用户可以直接向 AI 提问，例如：

- “总结今天市场的主要方向和强弱变化。”
- “复盘我的观察列表，按相对强弱和回撤排序。”
- “把这只股票的行情、历史走势、财务、估值和事件放在一起看。”
- “比较几个板块最近的轮动表现，标出需要进一步研究的方向。”

AI 负责选择工具、组合数据和解释结果；用户不需要记忆几十个接口名称。

### 2. 机会线索发现，而不是简单报价

除了实时行情，系统还能把市场简报、热点主题、板块复盘、股池、估值和观察列表放进同一个分析流程，帮助 AI 发现：

- 市场情绪和主要指数的变化
- 相对强弱、成交和趋势的异常组合
- 板块轮动和热点扩散线索
- 观察列表中的强弱分化
- 需要进一步核验的事件、财务或估值变化

这些结果是“研究线索”和“信息整理”，不代表买入信号、收益预测或投资建议。

### 3. 一次调用获取多维度个股快照

`stock_snapshot` 可以在边界受控的预算内，组合：

- 最新行情
- 最近历史走势
- 财务摘要
- 估值信息
- 股东、分红、解禁等事件
- 风险标签和数据完整性提示

它适合让 AI 先形成结构化全貌，再决定是否深入调用某一项数据。

### 4. 支持“观察—复盘—比较”的连续工作流

系统提供：

- 单股复盘和批量复盘
- 观察列表分析
- 多股票横向比较
- 板块成员和板块轮动复盘
- 交易日历和交易时段上下文
- 历史行情和技术指标

用户可以把一次性的问答变成固定的盘前、盘后和周度复盘流程。

### 5. 多数据源与 fallback

项目支持 AKShare 与智兔（Zhitu） Provider，并在适用场景下进行 fallback。响应会尽可能说明：

- 数据来源
- 数据时间和新鲜度
- 是否使用 fallback
- 是否存在 partial failure
- 数据质量启发式评分

数据质量评分用于提示数据完整性和可用性，不是投资置信度，也不是推荐分数。

### 6. 为 AI Host 设计的统一接口

项目通过标准 MCP stdio 接入：

- Codex
- Claude Code
- OpenClaw
- Hermes Agent
- 其他支持本地 stdio MCP 的 Host

默认 `retail_v1_preview` 工具档只暴露 10 个高层工具，降低 AI 选错工具和重复调用的概率；需要完整能力时可显式切换到 `full` 档，当前完整注册目录为 53 个工具。

## 典型使用场景

### 盘前信息整理

AI 汇总交易日、市场简报、主要板块和热点线索，输出“今天需要关注什么、哪些数据仍需核验”的清单。

### 盘后市场复盘

AI 结合市场概览、股池、板块轮动和交易日上下文，生成结构化复盘，明确数据时间、来源和缺失项。

### 观察列表复盘

用户输入一组代码，AI 按收益、相对强弱、回撤、成交和数据质量进行排序，并说明哪些结果需要进一步查证。

### 个股研究卡片

通过 `stock_snapshot` 形成行情、历史、财务、估值、事件和风险字段整合的研究卡片，适合作为人工研究的起点。

### 事件驱动复盘

将分红、解禁、回购、披露和财务事件与历史行情放在一起，帮助用户复盘事件前后发生了什么。

## 默认工具档

首次部署默认使用 `retail_v1_preview`，包含：

```text
stock_search
market_brief
stock_snapshot
stock_quote
stock_history
stock_review
watchlist_review
trading_calendar
sector_review
hot_theme_tracker
```

完整 `full` 档保留 53 个工具，覆盖财务、资金流、龙虎榜、北向资金、融资融券、ETF、可转债、期权期货、披露和股东事件等更深层能力。

## 产品边界与诚实承诺

- 不连接券商，不保存交易账户，不执行买卖或自动交易
- 不提供投资参考、投资建议、风险建议、收益承诺或荐股结论
- 不承诺第三方数据接口的 SLA、实时性、字段稳定性或完整性
- `freshness=realtime` 不等于当前正在交易
- `data_quality` 是数据可用性启发式提示，不是投资置信度
- fallback 后数据来源、单位和更新时间可能变化，用户应独立核验
- 智兔 token、数据授权、缓存和再分发权由用户按上游条款自行负责

## 给销售或交付人员的一句话

> `cn-stock-mcp` 不是替用户做投资决定，而是把中国市场数据、复盘和研究流程交给 AI 组织起来，让用户更快发现值得核验的线索、更系统地复盘自己的观察列表，并始终看到数据来源、时间和质量提示。
