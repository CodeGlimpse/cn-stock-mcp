# Support Policy

The latest published patch release is `0.2.2`; `0.2.3` is in release preparation. Initial commercial acceptance targets Windows 11 x64, regular CPython 3.13, Codex, and the 10-tool retail stdio profile. Record the exact Codex client and version. Other Host templates remain integration references, outside the initial acceptance commitment.

Installation/configuration support lasts 7 days after acceptance, with a response within 2 business days. Initial acceptance lasts 3 days; failed installation allows at most 2 remediation attempts totaling no more than 7 days. If acceptance remains impossible in the agreed environment, refunds follow the transaction platform's rules. See [the delivery terms](docs/COMMERCIAL_DELIVERY_TEMPLATE.md) for the order-specific record.

Support covers installation, self-checks, MCP connectivity, tool schemas, source/freshness metadata, and redacted diagnostics. It does not guarantee third-party upstream availability, field stability, data timeliness, licensing rights, investment outcomes, or suitability for a particular decision.

When reporting a problem, include the version, operating system, Host name, reproduction steps, and redacted `--doctor --json` output. Do not attach token configuration files or unredacted URLs. See [docs/SUPPORT.md](docs/SUPPORT.md) for details.
