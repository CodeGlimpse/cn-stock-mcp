# Deployment and Runtime Support

The GitHub source code is free and licensed under MIT. Charges apply only to separately agreed deployment and runtime support, not code usage, Token resale, or market-data licensing.

The service targets cn-stock-mcp 0.2.3 on Windows 11 x64, regular CPython 3.13, a specified Codex client, and the 10-tool retail stdio profile. The 13 Windows Host guides are configuration references and do not expand the agreed service scope or represent completed client certifications. Verify release availability and checksums before deployment.

Deployment and runtime support lasts 7 days after customer acceptance, with a response within 2 business days. Initial acceptance lasts 3 days; failed installation allows at most 2 remediation attempts totaling no more than 7 days. If acceptance remains impossible in the agreed environment, refunds follow the transaction platform's rules. See [the service terms](docs/COMMERCIAL_DELIVERY_TEMPLATE.md) for the order-specific record.

Support covers installation, configuration, reproducible code runtime problems, MCP connectivity, and arrangements for defects in the agreed version. Third-party service availability, additional features and scope changes remain subject to their own terms and agreement. Development checks exclude live market queries and actual AI Host acceptance at the user's request; customer acceptance is recorded separately after deployment.

When reporting a problem, include versions, reproduction steps and redacted diagnostics. Do not attach Token files, complete Host configuration, private authorization agreements or unredacted logs. See [data-use boundaries](docs/DATA_RIGHTS_REGISTER.md) and [third-party notices](docs/THIRD_PARTY_LICENSES.md).
